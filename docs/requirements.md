# プログラミング学習Webアプリ 要件定義

> ステータス: 要件ヒアリング中（未決事項あり）
> 最終更新: 2026-10-19

## 1. 決定事項

### 1.1 背景

プロジェクトを開始するにあたり、各個人のプログラミング能力と知識を向上させる。

### 1.2 対象者（レベル区分）

| レベル | 定義 |
| --- | --- |
| 初級 | まったく何も学んだことのない初学者 |
| 中級 | 書いてある処理は読めるが、自分の力で書くことはできない |
| 上級 | リファクタリングや安全な設計ができ、プロダクト全体の責任者を目指す |

### 1.3 アプリの内容

- プログラミングを学べる **Webアプリケーション** である
- 上記の対象者（初級／中級／上級）でコンテンツを **ジャンル分け** する
- **実際の現場で使える** 学びを得られる内容にする
- **実際に手を動かしながら** 学べる
- 対象言語は次の3つ
  - Swift
  - JavaScript（TypeScript）
  - Ruby（Rails）

### 1.4 利用者・認証

- 利用者は **社内メンバーのみ**
- **ログインあり**。認証は **GitHubログイン**
- ログインできるのは、管理者が **許可リストに登録したGitHubユーザーだけ**
- レベル（コース）は **本人が選ぶ**。各コースの入口に前提のチェックリストを置く
- メンター・管理者向けに **進捗一覧とユーザー管理の画面** を作る。メンターは受講者のPRの差分をアプリ上で見られる
- 学習の進捗はユーザーごとに記録する

### 1.5 学習体験

- 受講者は **全員Macを持っている**
- 初級（JS/TS、Ruby）: **ブラウザ内で実行** して、自動で判定する
- 初級（Swift）: **Xcode（Playground）で解き**、アプリ上のクイズで理解を確認する
- 初級の最後に、環境構築とGit／GitHubのレッスンを置く
- 中級・上級: **ローカルで解いてPRを出し、GitHub Actionsのテストで判定** する
  - 課題リポジトリは **受講者の個人アカウント** に作る
  - リポジトリの単位は **受講者 × コースで1つ**（1課題 ＝ 1PR）
  - リポジトリは **private**
- 上級: テストに加えて **AI（Claude）がPRをレビュー** する
  - APIキーは当面 **開発者個人のキー** を使い、本格運用の前に会社のキーへ切り替える。回数上限を設ける
- iOS固有の課題: **ロジックはLinuxランナーでテストし、画面部分はAIレビューのみ**
- コード実行サーバーは持たない

詳細は [architecture.md](architecture.md) を参照。

### 1.6 スコープ

- MVPは **3言語 × 全レベル（初級／中級／上級）**
- 1コースあたり **5〜8レッスン**
- 教材は **Claudeが下書きし、社内メンバーがPRでレビュー** する

### 1.7 技術・インフラ

- アプリ: **Next.js ＋ TypeScript**
- デプロイ先: **Vercel**
- 教材・課題・テストケース: **リポジトリ内のMarkdownで管理**（追加・修正はPRで行う）

### 1.8 データの持ち方

- 教材・課題・テストケース: このリポジトリと、コースごとのテンプレートリポジトリ
- ユーザー、進捗、提出結果、AIレビュー結果: PostgreSQL（Neon）＋ Drizzle ORM
