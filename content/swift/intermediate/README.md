## このコースについて

既存の iOS アプリ「さくらマート」に、チケットどおりに機能を追加したり、バグを直したりするコースです。Xcode で解き、GitHub にPRを出して提出します。

**ゴール**: 既存の iOS アプリに、APIからデータを取得して表示する機能をチケットどおりに追加できること。ロジックにテストを書いて、自分の変更を確認できること。

### 前提チェックリスト

次のすべてに自信を持ってチェックできれば、このコースから始める目安です。

- [ ] 仕様書を読んで、業務ロジックを関数や型として書ける
- [ ] オプショナルを `if let` や `guard let` で安全に扱える
- [ ] `struct` と `class` の違いを説明できる
- [ ] 「共通: 開発の準備」を終えている（ターミナル、Git、PR、デバッグ）

### 進め方

1. 下の「はじめに」の手順で、テンプレートから自分の課題リポジトリを作り、GitHub App をインストールする（最初に一度だけ）
2. 各レッスンの **解説** を読む
3. **演習**: 課題の開始ブランチから作業ブランチを切り、チケットを実装して、開始ブランチに向けてPRを出す。GitHub Actions のテスト（Linux の `swift test`）がすべて通った状態でマージすると合格
4. **確認クイズ** に答える

演習とクイズの両方に合格すると、レッスン完了です。どの課題からでも始められます。

### 題材: さくらマート（iOS版）

| 要素 | 内容 |
| --- | --- |
| 画面 | SwiftUI（iOS 17 以上） |
| ロジック | Swift Package（`SakuraMartKit`）。ViewModel もここに置く |
| テスト | Swift Testing。判定は GitHub Actions の Linux で行う |

画面（SwiftUI）の部分は Linux ではテストできないため、自動の判定はロジック（`SakuraMartKit`）だけで行います。画面は Xcode のシミュレーターで動かして確認してください（上級では、画面の部分を AI がレビューします）。
