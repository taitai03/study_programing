## Xcode をインストールする

Swift のコードを書いて動かすには、Apple が提供している開発ツール **Xcode** を使います。iOSアプリの開発でも、現場では Xcode を使います。

1. Mac の **App Store** を開き、「Xcode」を検索してインストールする（10GB 以上あるので、時間に余裕を持って始めてください）
2. インストールが終わったら Xcode を起動する。追加のコンポーネントのインストールを求められたら、そのまま進める
3. 「Install」画面で iOS を選ぶよう求められた場合は、チェックを入れてインストールする

会社のMacでインストールできない場合は、メンターに相談してください。

## Playground でコードを動かす

**Playground** は、Swift のコードを書いてすぐに結果を確かめられる Xcode の機能です。アプリを作らなくても、コードの一部だけを動かせます。このコースの演習は、すべて Playground で行います。

1. このページの下にある「Playground をダウンロード」から zip をダウンロードして、ダブルクリックで展開する
2. できた `SakuraMart-01-xcode-errors.playground` をダブルクリックすると、Xcode で開く
3. 左下（またはコードの行番号の横）にある **▶ ボタン** を押すと実行される。`Shift + Command + Return` でも実行できる
4. 画面の下に **デバッグエリア** が開き、`print` の結果が表示される。表示されないときは `Shift + Command + Y` で開く

自分で新しい Playground を作るときは、Xcode のメニューの **File > New > Playground...** から **macOS > Blank** を選びます。

## プログラムは上から順に実行される

```swift
print("さくらマートへようこそ")
print(1000 + 500)
```

`print(...)` は、かっこの中の値をデバッグエリアに表示する命令です。実行すると、次のように表示されます。

```text
さくらマートへようこそ
1500
```

- `"さくらマートへようこそ"` のように `"` で囲んだものは **文字列**（文章）です
- `1000 + 500` のように囲まないものは **数値** で、計算ができます
- `//` から行の終わりまでは **コメント** で、実行されません

Playground では、右側の細い領域（結果サイドバー）にも、各行の値が表示されます。

## エラーは「どこで」「何が」起きたかを教えてくれる

Swift は、**実行する前に** コード全体をチェックします（コンパイルといいます）。問題があると、実行されずに **コンパイルエラー** が表示されます。エラーがある行には赤い印が付き、メッセージが表示されます。

```swift
let price = 1000
print(prise)
```

```text
error: cannot find 'prise' in scope
```

| 部分 | 例 | 意味 |
| --- | --- | --- |
| 場所 | 赤い印が付いた行 | エラーが見つかった場所 |
| メッセージ | `cannot find 'prise' in scope` | `prise` という名前が見つからない |

`price` と書くべきところを `prise` と書いていたことが分かります。

### よく出会うエラー

| エラー | よくある原因 |
| --- | --- |
| `cannot find 'xxx' in scope` | 名前のタイプミス。定義する前に使っている |
| `cannot convert value of type 'Int' to expected argument type 'String'` | 文字列が必要な場所に数値を渡している。文字列と数値を `+` でつなごうとしている |
| `expected '}' ...` | `{` と `}` の数が合っていない |
| `cannot assign to value: 'xxx' is a 'let' constant` | `let` で作った定数を変えようとしている（レッスン2で学びます） |

### 文字列の中に値を埋め込む

文字列と数値は `+` でつなげません。文字列の中に値を入れたいときは、`\( )` を使います（文字列補間といいます）。

```swift
let fee = 550
print("送料: \(fee)円") // 送料: 550円
```

## エラーを直すときの手順

1. 赤い印が付いた **行** を見る
2. **メッセージ** を読んで、何が起きたかを考える（英語でも、単語を拾えば意外と分かります）
3. 直して、もう一度実行する。エラーが複数あるときは、**上から順に** 直していく

Xcode は、直し方の候補（**Fix-it**）を出してくれることがあります。メッセージの横の「Fix」を押すと自動で直りますが、**何が変わったのかを必ず確認** しましょう。
