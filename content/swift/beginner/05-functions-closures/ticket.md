## 背景
さくらマートのアプリでクーポンを使えるようにすることになりました。販売チームから、クーポンの割引ルールの仕様書が届いています。
このルールを、関数として作ってください。今回は関数の形も用意していません。白紙から書きます。

## 仕様書
### 関数1: `couponDiscount(amount:type:value:minPurchase:)`
クーポンの割引額（`Int`）を返す。`amount`、`value`、`minPurchase` は `Int`、`type` は `String`。`minPurchase` は省略でき、省略したときは 0。

- `amount`（金額）が `minPurchase`（最低購入金額）より小さい場合は、割引しない（0を返す）
- `type` が `"amount"`（定額）の場合: `value` 円を割り引く。ただし、割引額は `amount` を超えない
- `type` が `"percent"`（定率）の場合: `amount` の `value` %を割り引く（端数は切り捨て）
- それ以外の `type` の場合は、割引しない

### 関数2: `couponAvailableProducts(_:budget:)`
商品の一覧（`[(name: String, price: Int)]`）と予算（`Int`）を受け取り、税込価格（端数は切り捨て）が予算以下の商品の **名前の配列** を、もとの順番のまま返す。`filter` と `map` を使う。

## 受け入れ条件（セルフチェック）
- [ ] 3,000円に「500円引き・2,000円以上」のクーポンを使うと、割引額は500円
- [ ] 1,500円には「500円引き・2,000円以上」のクーポンは使えず、ちょうど2,000円なら使える
- [ ] 300円に「500円引き」のクーポンを使うと、割引額は300円（金額を超えない）
- [ ] 3,333円に「10%引き」のクーポンを使うと、割引額は333円
- [ ] 知らない種類のクーポンでは割引しない
- [ ] 予算500円で買える商品が「国産りんごジュース 1L」「ふっくら食パン」「天然水 2L」「大学ノート 5冊セット」になる（ノートは税込でちょうど500円）
