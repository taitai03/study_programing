## このレッスンの進め方

最後のレッスンです。今回は、やることを細かく分けた説明はありません。**仕様書を読んで、どんな型と関数が必要かを自分で考えて** 作ります。

実際のアプリ開発でも、「この関数をこう書いて」と言われることはほとんどありません。仕様書や画面のデザインから、必要な型と処理を自分で考えます。

## 仕様書から作るときの手順

1. **入力と出力を確認する**: 何を受け取って、何を返すのか。型の名前やプロパティの名前まで確認する
2. **型を先に作る**: 仕様書に出てくる「もの」（会員ランク、計算結果など）を、enum や struct で表す
3. **計算の順番を書き出す**: さくらマートの料金計算は順番が決まっている（下の表）。順番を間違えると金額が変わる
4. **少しずつ動かす**: 1つ書いたら `print` で結果を確かめてから、次に進む
5. **特別なケースを確かめる**: かごが空のとき、クーポンがないとき、境目の金額のとき

## さくらマートの料金計算（おさらい）

| 順番 | 項目 | 計算 |
| --- | --- | --- |
| 1 | 小計 | 商品の価格（税抜）× 数量 の合計 |
| 2 | 会員ランク割引 | 小計 × 割引率（一般 0%、シルバー 5%、ゴールド 10%） |
| 3 | クーポン割引 | ランク割引のあとの金額に適用する。最低購入金額も、ランク割引のあとの金額で判定する |
| 4 | 消費税 | 割引後の金額 × 10% |
| 5 | 送料 | 550円。4の消費税を加えた金額が5,000円以上なら無料 |
| 6 | 合計 | 消費税を加えた金額 ＋ 送料 |

**ポイント**: 消費税を加えた金額（送料を含まない）の1%。ゴールド会員は2%。端数はすべて切り捨てます。

## 新しく使う道具

### `Equatable`: 値どうしを `==` で比べられるようにする

自分で作った struct は、そのままでは `==` で比べられません。型の名前のあとに `: Equatable` と書くと、すべてのプロパティが同じかどうかで比べられるようになります。

```swift
struct Money: Equatable {
    let amount: Int
}
print(Money(amount: 100) == Money(amount: 100)) // true
```

セルフチェックの `check(...)` は `==` で比べるので、計算結果の型には `Equatable` が必要です。

### enum のプロパティで「種類ごとの値」を持たせる

会員ランクごとの割引率のように、選択肢ごとに決まった値は、enum の計算プロパティにまとめると、使う側がすっきりします。

```swift
enum MemberRank {
    case general, silver, gold

    var discountRate: Int {
        switch self {
        case .general: return 0
        case .silver: return 5
        case .gold: return 10
        }
    }
}

let rank: MemberRank = .gold
print(rank.discountRate) // 10
```

### オプショナルのクーポン

クーポンは使わないこともあるので、`Coupon?` で受け取ります。レッスン6の `guard let` や `if let` を使って、クーポンがあるときだけ割引を計算しましょう。
