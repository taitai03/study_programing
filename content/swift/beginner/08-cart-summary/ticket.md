## 背景
アプリの注文確認画面に、支払う金額の内訳を表示します。画面は別の担当者が作るので、あなたは内訳を計算する部分を担当します。
商品・かごの行・クーポンの型は Playground に用意してあります。

## 仕様書
### 1. `MemberRank`（会員ランク）を enum で作る
- 選択肢は `general`（一般）、`silver`（シルバー）、`gold`（ゴールド）
- `discountRate`: 割引率（%）。一般 0、シルバー 5、ゴールド 10
- `pointRate`: ポイント付与率（%）。ゴールド 2、それ以外 1

### 2. `CheckoutSummary`（金額の内訳）を struct で作る
次の `Int` のプロパティを持ち、`Equatable` にする。プロパティはこの順番で定義する（自動で用意されるイニシャライザの引数の順番になる）。

| プロパティ | 内容 |
| --- | --- |
| `subtotal` | 小計（税抜） |
| `rankDiscount` | 会員ランク割引の額 |
| `couponDiscount` | クーポン割引の額 |
| `tax` | 消費税の額 |
| `shippingFee` | 送料 |
| `total` | 支払う金額 |
| `points` | 付与ポイント |

### 3. `checkout(items:rank:coupon:)` を作る
`checkout(items: [CartItem], rank: MemberRank, coupon: Coupon?) -> CheckoutSummary`

- 計算は、解説の「さくらマートの料金計算」の順番どおりに行う。端数はすべて切り捨て
- クーポンの割引: 定額（`.amount`）は `value` 円（ただし割引前の金額を超えない）、定率（`.percent`）は `value` %
- かごが空のときは、送料も含めてすべて 0

## 受け入れ条件（セルフチェック）
- [ ] 一般会員・クーポンなしで、りんごジュース3個と食パン2個の内訳が正しい（合計2,409円、18ポイント）
- [ ] ゴールド会員が10%引きクーポンを使ったときの内訳が正しい（合計4,764円、84ポイント）
- [ ] シルバー会員が500円引きクーポンを使い、送料が無料になるときの内訳が正しい（合計5,657円）
- [ ] ランク割引のあとの金額が最低購入金額に届かないと、クーポンは使えない
- [ ] かごが空なら、すべて 0 になる
