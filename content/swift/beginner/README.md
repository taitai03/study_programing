## このコースについて

プログラミングをまったく学んだことがない人向けの、Swiftのコースです。iOSアプリの中で動く業務ロジック（料金計算、条件による振り分け、データの集計）を、Swiftで書けるようになることを目指します。

**ゴール**: アプリの中の業務ロジックを、Swiftの関数や型として仕様どおりに書けるようになること。エラーを読んで、自分で直せるようになること。

### 前提チェックリスト

- [ ] Mac を使える（Xcode は Mac でしか動きません）
- [ ] Mac に Xcode をインストールできる（1回目のレッスンで手順を説明します。ダウンロードに時間がかかるので、早めに始めてください）

### 進め方

各レッスンは次の3つでできています。確認クイズに全問正解すると、レッスン完了です。

1. **解説** を読む
2. **演習（Playground）**: Playground をダウンロードして Xcode で開き、チケット（依頼）を読んでコードを書く。実行すると、セルフチェックの結果が ✅ / ❌ で表示されます
3. **確認クイズ** に答える

Playground の演習はこのアプリでは判定しません。すべて ✅ になるまで、自分で確かめてからクイズに進んでください。

### 題材: さくらマート

演習はすべて、架空のECショップ「さくらマート」の業務を題材にしています。料金計算のルールは次のとおりです（全コース共通）。

| ルール | 内容 |
| --- | --- |
| 消費税 | 10%。端数は切り捨て |
| 送料 | 550円。税込5,000円以上なら無料 |
| 会員ランク割引 | 一般 0%、シルバー 5%、ゴールド 10% |
| ポイント | 税込の商品金額の1%（ゴールド会員は2%）。端数は切り捨て |
