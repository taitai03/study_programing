## ターミナルとは

**ターミナル** は、文字でコンピューターに指示を出すアプリです。Finder でフォルダを開いたりファイルを作ったりする操作を、コマンド（命令）で行います。

開発では、ターミナルを毎日使います。アプリを起動する、テストを実行する、Git で変更を記録する、ライブラリを入れる、といった操作の多くは、ターミナルでしかできないか、ターミナルのほうが速いからです。

Mac では「アプリケーション > ユーティリティ > ターミナル」から起動できます（`Command + Space` で「ターミナル」と入力しても開けます）。VS Code の中のターミナル（メニューの「ターミナル > 新しいターミナル」）も同じように使えます。

### 画面の見方

```text
taro@MacBook ~ %
```

最後の `%`（環境によっては `$`）のあとにコマンドを入力し、`Return` キーで実行します。`~` は **今いるフォルダ** を表しています（`~` はホームフォルダのこと）。

このコースの解説では、`%` を省略してコマンドだけを書きます。

## パス: ファイルやフォルダの住所

ファイルやフォルダの場所は **パス** で表します。フォルダの区切りは `/` です。

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `/` で始まる | 絶対パス。いちばん上のフォルダからの住所 | `/Users/taro/projects` |
| `~` | ホームフォルダ（`/Users/自分の名前`） | `~/projects` |
| `.` | 今いるフォルダ | `./README.md` |
| `..` | 1つ上のフォルダ | `../other-project` |
| それ以外 | 相対パス。今いるフォルダからの住所 | `src/app` |

## 基本のコマンド

| コマンド | 意味 | 例 |
| --- | --- | --- |
| `pwd` | 今いるフォルダを表示する | `pwd` |
| `ls` | フォルダの中身を表示する。`-a` で隠しファイル（`.` で始まる）も表示 | `ls -a` |
| `cd` | フォルダを移動する | `cd ~/projects` |
| `mkdir` | フォルダを作る。`-p` で途中のフォルダもまとめて作る | `mkdir -p sakura-mart/docs` |
| `touch` | 空のファイルを作る | `touch memo.txt` |
| `cat` | ファイルの中身を表示する | `cat README.md` |
| `cp` | コピーする | `cp .env.example .env` |
| `mv` | 移動する・名前を変える | `mv memo.txt notes.txt` |
| `rm` | 削除する（ゴミ箱に入らず、元に戻せない） | `rm notes.txt` |

`rm` で消したファイルは、ゴミ箱に入らずに **すぐに消えます**。特に `rm -rf`（フォルダごと確認なしで消す）は、パスを間違えると大切なファイルをまとめて失います。実行する前に、`pwd` と `ls` で場所と対象を必ず確認しましょう。

### 入力を楽にする

- `Tab` キー: ファイル名やフォルダ名を途中まで入力して押すと、残りを補ってくれる（タイプミスも防げる）
- `↑` キー: 前に実行したコマンドを呼び出す
- `Control + C`: 実行中のコマンドを止める（開発用のサーバーを止めるときなど）

## コマンドのエラーを読む

コマンドもエラーメッセージで原因を教えてくれます。

```text
cd: no such file or directory: projcts
```

「`projcts` というファイルやフォルダはない」という意味です。つづりの間違いか、今いるフォルダが違うことが原因です。`pwd` と `ls` で確認しましょう。

| メッセージ | よくある原因 |
| --- | --- |
| `no such file or directory` | パスのつづりの間違い。今いるフォルダが思っている場所と違う |
| `command not found: xxx` | コマンド名の間違い。そのツールがインストールされていない |
| `permission denied` | そのファイルを操作する権限がない |

`command not found` が出たときに、ネットで見つけた `sudo` 付きのコマンドをそのまま実行するのはやめましょう。`sudo` は管理者の権限で実行するコマンドで、間違えるとPC全体の設定を壊すことがあります。

## やってみよう

新しく参加したプロジェクトで、手順書に「作業用のフォルダを用意してください」と書かれていたとします。ターミナルで次の操作をしてみましょう。

1. ホームフォルダに `projects` フォルダを作り、その中に移動する
2. `projects` の中に `sakura-mart/docs` フォルダをまとめて作る
3. `sakura-mart` に移動して、`README.md` という空のファイルを作る
4. `ls -a` で中身を確認し、`pwd` で今いる場所を確認する

```bash
mkdir ~/projects
cd ~/projects
mkdir -p sakura-mart/docs
cd sakura-mart
touch README.md
ls -a
pwd
```
