## このコースについて

各言語の初級を終えたあと、中級に入る前に受けるコースです。中級からは、ブラウザではなく自分のPCでコードを書き、GitHubのプルリクエスト（PR）で課題を提出します。そのために必要な道具の使い方と、自分で調べて解決する方法を学びます。

**ゴール**: ターミナル・Git・GitHubを使って、チームの開発の流れ（ブランチを切る → commit → PR → レビュー → マージ）に参加できるようになること。分からないことを、自分で調べて解決できるようになること。

### 前提チェックリスト

- [ ] いずれかの言語の初級を終えている
- [ ] 自分のPC（Mac）で、アプリのインストールができる
- [ ] GitHub のアカウントを持っている（このアプリにログインしたアカウント）

### 進め方

各レッスンは、**解説** と **確認クイズ** でできています。確認クイズに全問正解すると、レッスン完了です。

解説の中の「やってみよう」は、自分のPCで実際に手を動かす練習です。判定はしませんが、中級の課題ではここで練習した操作を毎回使うので、必ずやっておきましょう。

> PRを実際に出して判定する練習課題は、GitHub連携の機能ができたあとに追加します。それまでは確認クイズで完了できます。
