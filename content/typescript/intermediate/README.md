## このコースについて

既存の Next.js アプリ「さくらマート 管理画面」に、チケットどおりに機能を追加したり、バグを直したりするコースです。ローカルの開発環境で解き、GitHub にPRを出して提出します。

**ゴール**: 既存の Next.js アプリに、画面・API・DBにまたがる機能をチケットどおりに追加できること。テストを書いて、自分の変更を確認できること。

### 前提チェックリスト

次のすべてに自信を持ってチェックできれば、このコースから始める目安です。

- [ ] 仕様書を読んで、業務ルールを関数として書ける
- [ ] 配列とオブジェクトを組み合わせたデータを集計できる
- [ ] TypeScriptの型注釈の意味が分かり、型エラーを読んで直せる
- [ ] 「共通: 開発の準備」を終えている（ターミナル、Git、PR、デバッグ）

### 進め方

1. 下の「はじめに」の手順で、テンプレートから自分の課題リポジトリを作り、GitHub App をインストールする（最初に一度だけ）
2. 各レッスンの **解説** を読む
3. **演習**: 課題の開始ブランチから作業ブランチを切り、チケットを実装して、開始ブランチに向けてPRを出す。GitHub Actions のテストがすべて通った状態でマージすると合格
4. **確認クイズ** に答える

演習とクイズの両方に合格すると、レッスン完了です。どの課題からでも始められます（課題ごとに開始ブランチがあるため、前の課題の出来には左右されません）。

### 題材: さくらマート 管理画面

| 要素 | 使っているもの |
| --- | --- |
| フレームワーク | Next.js（App Router）、TypeScript |
| DB | SQLite ＋ Drizzle ORM |
| スタッフのログイン | Auth.js |
| テスト | Vitest、React Testing Library |

アプリの動かし方や業務のルールは、リポジトリの README.md にまとめてあります。最初に一度、全体を動かして画面とコードを眺めておくと、課題に入りやすくなります。
