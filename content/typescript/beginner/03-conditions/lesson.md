## 業務ルールの多くは「もし〜なら」

業務のルールは、ほとんどが「もし〜なら、こうする」という形をしています。

- もし税込5,000円以上 **なら** 送料無料、**そうでなければ** 550円
- もしゴールド会員 **なら** 10%引き

これをコードにするのが `if` 文です。

```ts
const totalWithTax = 6200;

if (totalWithTax >= 5000) {
  console.log("送料無料です");
} else {
  console.log("送料は550円です");
}
```

`if (条件) { ... }` の条件が正しい（`true`）ときだけ、`{ }` の中が実行されます。条件が正しくない（`false`）ときは、`else { ... }` の中が実行されます。

## 比べるための記号

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `===` | 等しい | `rank === "gold"` |
| `!==` | 等しくない | `rank !== "general"` |
| `>` / `<` | より大きい / より小さい | `quantity > 10` |
| `>=` / `<=` | 以上 / 以下 | `total >= 5000` |

> **注意**: 「等しい」は `=` ではなく `===` です。`=` は「変数に値を入れる」意味になります。

## 3つ以上に分ける: `else if`

```ts
const rank = "silver";

if (rank === "gold") {
  console.log("10%引き");
} else if (rank === "silver") {
  console.log("5%引き");
} else {
  console.log("割引なし");
}
```

上から順に条件を調べて、最初に当てはまったところだけが実行されます。

## 条件を組み合わせる: `&&` と `||`

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `&&` | かつ（両方とも正しい） | `stock > 0 && quantity <= 10` |
| `\|\|` | または（どちらかが正しい） | `rank === "gold" \|\| rank === "silver"` |
| `!` | ではない | `!isMember` |

## 関数の中で答えを返す: `return`

演習では、ルールを **関数** の中に書きます。関数は「値を受け取って、答えを返す」部品です（詳しくはレッスン5で学びます）。今は次の書き方だけ覚えておけば大丈夫です。

```ts
function getShippingFee(totalWithTax: number): number {
  if (totalWithTax >= 5000) {
    return 0; // ここで答えを返して、関数は終わる
  }
  return 550;
}

console.log(getShippingFee(6200)); // 0
console.log(getShippingFee(3000)); // 550
```

`return` に来ると、そこで答えを返して関数が終わります。そのため、上の例では `else` を書かなくても正しく動きます。

## 境目の値に気をつける

「5,000円 **以上**」なら `>=`、「5,000円 **を超える**」なら `>` です。1文字の違いで、ちょうど5,000円のお客さんの送料が変わってしまいます。ルールを書いたら、**境目の値（4,999円、5,000円）** で正しく動くかを必ず確かめましょう。
