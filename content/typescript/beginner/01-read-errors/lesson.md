## プログラムは上から順に実行される

プログラムは、コンピューターへの指示を並べたものです。書いた指示は **上から順番に** 実行されます。

```ts
console.log("さくらマートへようこそ");
console.log(1000 + 500);
```

`console.log(...)` は、かっこの中の値を「出力」に表示する命令です。実行すると、次のように表示されます。

```text
さくらマートへようこそ
1500
```

- `"さくらマートへようこそ"` のように `"` で囲んだものは **文字列**（文章）です
- `1000 + 500` のように囲まないものは **数値** で、計算ができます
- 1つの命令の終わりには `;` を付けます

右のエディタの「実行」ボタンを押すと、書いたコードが実行されて、下の「出力」に結果が出ます。

## エラーは「どこで」「何が」起きたかを教えてくれる

プログラムを書いていると、必ずエラーに出会います。エラーは失敗ではなく、**コンピューターが問題の場所を教えてくれている** ものです。現場のエンジニアも、毎日エラーメッセージを読んで直しています。

たとえば、次のコードを実行すると、

```ts
const price = 1000;
console.log(prise);
```

次のようなエラーが出ます。

```text
ReferenceError: prise is not defined（2行目）
```

エラーメッセージは3つの部分に分けて読みます。

| 部分 | 例 | 意味 |
| --- | --- | --- |
| エラーの種類 | `ReferenceError` | 存在しない名前を使った |
| メッセージ | `prise is not defined` | `prise` は定義されていない |
| 場所 | `2行目` | 2行目で起きた |

2行目を見ると、`price` と書くべきところを `prise` と書いていることが分かります。

### よく出会うエラー

| エラー | よくある原因 |
| --- | --- |
| `ReferenceError: xxx is not defined` | 名前のタイプミス。定義する前に使っている |
| `SyntaxError` | かっこや `"` の閉じ忘れなど、書き方の間違い |
| `TypeError: xxx is not a function` | 関数ではないものを `()` で呼び出している |

### エディタの赤い波線

このエディタは、実行する前から問題のありそうな場所に **赤い波線** を引いてくれます。波線にマウスを乗せると、理由が表示されます。TypeScript（このコースで使う言語）が、書いたコードを事前にチェックしてくれているからです。

## エラーを直すときの手順

1. エラーメッセージの **場所（行番号）** を見る
2. **メッセージ** を読んで、何が起きたかを考える（英語でも、単語を拾えば意外と分かります）
3. 直して、もう一度実行する。別のエラーが出たら、また1から

一度に全部を理解する必要はありません。演習では、まだ学んでいない書き方（`function` や `if`）も出てきますが、今は「エラーを手がかりに直す」ことに集中してください。
