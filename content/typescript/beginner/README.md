## このコースについて

プログラミングをまったく学んだことがない人向けのコースです。ブラウザだけで学べるので、準備は必要ありません。

**ゴール**: 業務のルール（料金計算、条件による振り分け、データの集計）を、TypeScriptの関数として仕様どおりに書けるようになること。エラーメッセージを読んで、自分で直せるようになること。

### 前提チェックリスト

なし。プログラミング未経験から始められます。

### 進め方

各レッスンは次の3つでできています。演習とクイズの両方に合格すると、レッスン完了です。

1. **解説** を読む
2. **演習**: 業務のチケット（依頼）を読んで、右のエディタでコードを書く。「提出して判定」で受け入れ条件を自動でチェックします
3. **確認クイズ** に答える

分からないときは、ヒントを開いてください。最後のレッスンでは、仕様書だけを見て白紙からプログラムを作ります。

### 題材: さくらマート

演習はすべて、架空のECショップ「さくらマート」の業務を題材にしています。料金計算のルールは次のとおりです（全コース共通）。

| ルール | 内容 |
| --- | --- |
| 消費税 | 10%。端数は切り捨て |
| 送料 | 550円。税込5,000円以上なら無料 |
| 会員ランク割引 | 一般 0%、シルバー 5%、ゴールド 10% |
| ポイント | 税込の商品金額の1%（ゴールド会員は2%）。端数は切り捨て |
