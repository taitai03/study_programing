## 値に名前を付ける: `const`

同じ値を何度も使うときや、値の意味を分かりやすくしたいときは、**変数** に入れて名前を付けます。

```ts
const price = 398;
const quantity = 3;
console.log(price * quantity); // 1194
```

`const 名前 = 値;` と書くと、その名前で値を使えるようになります。名前は、何の値かが分かるように付けます（`a` や `x` ではなく `price` や `quantity`）。

### 計算に使う記号

| 記号 | 意味 | 例 | 結果 |
| --- | --- | --- | --- |
| `+` | 足し算 | `1000 + 550` | `1550` |
| `-` | 引き算 | `1000 - 100` | `900` |
| `*` | 掛け算 | `398 * 3` | `1194` |
| `/` | 割り算 | `1000 / 4` | `250` |

## あとで値を変える: `let`

`const` で作った変数は、あとから値を変えられません。値を変えたいときは `let` を使います。

```ts
let total = 0;
total = total + 1000;
total = total + 500;
console.log(total); // 1500
```

**基本は `const` を使い、どうしても値を変える必要があるときだけ `let` を使う** のが現場の書き方です。値が途中で変わらないほうが、コードを読む人が安心できるからです。

## 文字列の中に値を埋め込む: テンプレートリテラル

`` ` ``（バッククォート）で囲むと、`${...}` の中に変数や計算を埋め込めます。

```ts
const productName = "国産りんごジュース 1L";
const price = 398;
console.log(`${productName}: ${price}円`);
// 国産りんごジュース 1L: 398円
```

## お金の計算は整数で行う

税込価格を計算するとき、`price * 1.1` と書きたくなりますが、コンピューターは小数の計算で **ごくわずかな誤差** を出すことがあります。

```ts
console.log(0.1 + 0.2); // 0.30000000000000004
```

お金の計算で誤差が出ると、1円ずれた請求になってしまいます。そこで現場では、**小数を使わず整数で計算する** のが基本です。消費税10%なら、「110を掛けて100で割る」と書きます。

```ts
const subtotal = 1194;
const totalWithTax = Math.floor((subtotal * 110) / 100);
console.log(totalWithTax); // 1313
```

`Math.floor(...)` は **小数点以下を切り捨てる** 命令です。さくらマートでは、端数はすべて切り捨てるルールになっています。
