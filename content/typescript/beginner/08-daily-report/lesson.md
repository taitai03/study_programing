## このレッスンの進め方

最後のレッスンです。今回は、やることを細かく分けた説明はありません。**仕様書を読んで、どんな関数が必要かを自分で考えて** 作ります。

現場の仕事も同じです。「この関数をこう書いて」と言われることはほとんどなく、仕様書や依頼から、自分で作り方を考えます。

## 仕様書から作るときの手順

1. **入力と出力を確認する**: 何を受け取って、何を返すのか。型が書かれていれば、まず型を読む
2. **ルールを箇条書きにする**: 「キャンセルは除く」「同じ数のときは…」など、仕様書の条件を漏れなく書き出す
3. **小さく分ける**: 全部を1つの関数に書かず、「小計を求める」「商品ごとに数える」のように分ける
4. **少しずつ動かす**: 1つ書いたら `console.log` で結果を確かめてから、次に進む
5. **特別なケースを確かめる**: データが0件のとき、同じ値が並んだときなど

## 新しく使う道具

### 並べ替え: `sort`

配列を並べ替えるには `sort` を使います。並べ方は関数で指定します。

```ts
const items = [
  { productName: "天然水 2L", quantity: 10 },
  { productName: "ふっくら食パン", quantity: 3 },
  { productName: "国産りんごジュース 1L", quantity: 4 },
];

// 数量の多い順（大きい順）に並べる
items.sort((a, b) => b.quantity - a.quantity);
```

- `(a, b) => b.quantity - a.quantity` は「b のほうが大きければ b を前に」という意味で、**大きい順** になります
- 小さい順にしたいときは `a.quantity - b.quantity` です
- 値が同じものは、**もとの順番のまま** になります

### 先頭からいくつか取り出す: `slice`

```ts
const top3 = items.slice(0, 3); // 先頭から3つ（3つ未満なら、あるだけ）
```

### オブジェクトを配列にする: `Object.entries`

レッスン6の「種類ごとに数える」で作ったオブジェクトは、`Object.entries` で配列に変換できます。

```ts
const counts: Record<string, number> = { "天然水 2L": 10, "ふっくら食パン": 3 };

const list = Object.entries(counts).map((entry) => {
  return { productName: entry[0], quantity: entry[1] };
});
// [{ productName: "天然水 2L", quantity: 10 }, { productName: "ふっくら食パン", quantity: 3 }]
```

`Object.entries` は `[項目名, 値]` の組の配列を返します。`map` は、配列の要素を1つずつ変換して新しい配列を作るメソッドです（中級で詳しく学びます）。オブジェクトに追加した順番は保たれます。
