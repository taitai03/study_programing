## このコースについて

既存の Rails アプリ「さくらマート 管理画面」に、チケットどおりに機能を追加したり、バグを直したりするコースです。ローカルの開発環境で解き、GitHub にPRを出して提出します。前半（1〜3）は Ruby、後半（4〜9）は Rails を扱います。

**ゴール**: 既存の Rails アプリに、画面・DBにまたがる機能をチケットどおりに追加できること。RSpec でテストを書いて、自分の変更を確認できること。

### 前提チェックリスト

次のすべてに自信を持ってチェックできれば、このコースから始める目安です。

- [ ] 仕様書を読んで、業務ルールをメソッドやクラスとして書ける
- [ ] 配列、ハッシュ、ブロックを使ってデータを集計できる
- [ ] データベースの「テーブル」「行」「列」が何か説明できる
- [ ] 「共通: 開発の準備」を終えている（ターミナル、Git、PR、デバッグ）

### 進め方

1. 下の「はじめに」の手順で、テンプレートから自分の課題リポジトリを作り、GitHub App をインストールする（最初に一度だけ）
2. 各レッスンの **解説** を読む
3. **演習**: 課題の開始ブランチから作業ブランチを切り、チケットを実装して、開始ブランチに向けてPRを出す。GitHub Actions のテスト（RSpec）がすべて通った状態でマージすると合格
4. **確認クイズ** に答える

演習とクイズの両方に合格すると、レッスン完了です。どの課題からでも始められます。

### 題材: さくらマート 管理画面（Rails版）

| 要素 | 使っているもの |
| --- | --- |
| フレームワーク | Ruby on Rails 8、Hotwire（ERB） |
| DB | SQLite |
| スタッフのログイン | Rails 標準の認証 |
| テスト | RSpec、FactoryBot |

アプリの動かし方や業務のルールは、リポジトリの README.md にまとめてあります。最初に一度、全体を動かして画面とコードを眺めておくと、課題に入りやすくなります。
