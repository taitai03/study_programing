## このレッスンの進め方

最後のレッスンです。今回は、やることを細かく分けた説明はありません。**仕様書を読んで、どんなメソッドが必要かを自分で考えて** 作ります。

現場の仕事も同じです。「このメソッドをこう書いて」と言われることはほとんどなく、仕様書や依頼から、自分で作り方を考えます。

## 仕様書から作るときの手順

1. **入力と出力を確認する**: 何を受け取って、何を返すのか。返すハッシュのキーの名前まで確認する
2. **ルールを箇条書きにする**: 「キャンセルは除く」「同じ数のときは…」など、仕様書の条件を漏れなく書き出す
3. **小さく分ける**: 全部を1つのメソッドに書かず、「小計を求める」「商品ごとに数える」のように分ける
4. **少しずつ動かす**: 1つ書いたら `p` で結果を確かめてから、次に進む
5. **特別なケースを確かめる**: データが0件のとき、同じ値が並んだときなど

## 新しく使う道具

### 並べ替え: `sort_by`

配列を並べ替えるには `sort_by` を使います。ブロックの結果の **小さい順** に並びます。

```ruby
items = [
  { product_name: "天然水 2L", quantity: 10 },
  { product_name: "ふっくら食パン", quantity: 3 },
  { product_name: "国産りんごジュース 1L", quantity: 4 },
]

p items.sort_by { |item| item[:quantity] }  # 小さい順: 3, 4, 10
p items.sort_by { |item| -item[:quantity] } # 大きい順: 10, 4, 3
```

大きい順にしたいときは、ブロックの結果にマイナスを付けます（`reverse` で逆にする方法もあります）。

#### 同じ値のときの順番に注意

Rubyの `sort_by` は、ブロックの結果が同じ要素どうしの順番を **保証しません**。「同じ数のときは先に出てきたものを上に」という仕様があるときは、もとの順番（番号）も並べ替えの条件に入れます。

```ruby
items.sort_by.with_index { |item, index| [-item[:quantity], index] }
```

- `with_index` を付けると、ブロックで要素の番号（`index`）も受け取れます
- ブロックの結果を `[-数量, 番号]` の配列にすると、まず数量の大きい順、数量が同じなら番号の小さい順（先に出てきた順）に並びます

### 先頭からいくつか取り出す: `first`

```ruby
top3 = items.first(3) # 先頭から3つ（3つ未満なら、あるだけ）
```

### ハッシュを配列にする: `map`

レッスン5の「種類ごとに数える」で作ったハッシュも、`map` で配列に変換できます。ハッシュの `map` では、キーと値の2つを受け取ります。

```ruby
counts = { "天然水 2L" => 10, "ふっくら食パン" => 3 }

list = counts.map { |name, quantity| { product_name: name, quantity: quantity } }
# => [{ product_name: "天然水 2L", quantity: 10 }, { product_name: "ふっくら食パン", quantity: 3 }]
```

ハッシュは、キーを追加した順番を覚えています。そのため、変換した配列も、商品が先に出てきた順に並びます。
