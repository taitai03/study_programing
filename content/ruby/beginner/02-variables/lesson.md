## 値に名前を付ける: 変数

同じ値を何度も使うときや、値の意味を分かりやすくしたいときは、**変数** に入れて名前を付けます。

```ruby
price = 398
quantity = 3
puts price * quantity # => 1194
```

`名前 = 値` と書くと、その名前で値を使えるようになります。名前は、何の値かが分かるように付けます（`a` や `x` ではなく `price` や `quantity`）。

Rubyでは、変数の名前は **小文字と `_`（アンダースコア）** で書くのが決まりです。`total_with_tax` のように、単語を `_` でつなぎます（スネークケースと呼びます）。

変数には、あとから別の値を入れ直せます。

```ruby
total = 0
total = total + 1000
total += 500 # total = total + 500 と同じ
puts total # => 1500
```

### 変わらない値は定数にする

消費税率や送料のように、プログラムの中で変わらない値は、**大文字で始まる名前**（定数）にします。

```ruby
TAX_RATE = 10
SHIPPING_FEE = 550
```

定数にしておくと、「これは決まった値で、変えてはいけない」ことが読む人に伝わります。

### 計算に使う記号

| 記号 | 意味 | 例 | 結果 |
| --- | --- | --- | --- |
| `+` | 足し算 | `1000 + 550` | `1550` |
| `-` | 引き算 | `1000 - 100` | `900` |
| `*` | 掛け算 | `398 * 3` | `1194` |
| `/` | 割り算 | `1000 / 3` | `333` |
| `%` | 割った余り | `1000 % 3` | `1` |

## 文字列の中に値を埋め込む: 式展開

`"`（ダブルクォート）で囲んだ文字列の中に `#{...}` と書くと、変数や計算を埋め込めます。

```ruby
product_name = "国産りんごジュース 1L"
price = 398
puts "#{product_name}: #{price}円"
# => 国産りんごジュース 1L: 398円
```

`'`（シングルクォート）で囲んだ文字列では、`#{...}` はそのまま文字として表示されます。値を埋め込みたいときは `"` を使います。

文字列と数値を `+` でつなごうとすると `TypeError` になります。数値を文字列にしたいときは、式展開を使うか、`price.to_s` のように `to_s` で変換します。

## お金の計算は整数で行う

税込価格を計算するとき、`price * 1.1` と書きたくなりますが、コンピューターは小数の計算で **ごくわずかな誤差** を出すことがあります。

```ruby
p 0.1 + 0.2 # => 0.30000000000000004
```

お金の計算で誤差が出ると、1円ずれた請求になってしまいます。そこで現場では、**小数を使わず整数で計算する** のが基本です。消費税10%なら、「110を掛けて100で割る」と書きます。

```ruby
subtotal = 1194
total_with_tax = subtotal * 110 / 100
puts total_with_tax # => 1313
```

Rubyでは、**整数どうしの割り算は、小数点以下が切り捨てられます**（`1313.4` ではなく `1313` になる）。さくらマートでは端数はすべて切り捨てるルールなので、整数で計算すればそのままルールどおりになります。

割り算をする順番にも気をつけましょう。`subtotal / 100 * 110` と書くと、先に `1194 / 100` が `11` に切り捨てられてしまい、結果が `1210` になります。**掛け算を先に、割り算をあとに** するのがコツです。
